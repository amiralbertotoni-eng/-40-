AMIR & MIA — OUR LITTLE FOREVER

HOW TO PREVIEW
1. Keep index.html in a folder.
2. Open index.html in a web browser to preview it.
3. To edit the words, open index.html in a text editor and search for the text you want to change.

HOW TO PUBLISH FREE WITH GITHUB PAGES
1. Sign in to GitHub and create a new public repository, for example: amir-mia-wedding.
2. Upload index.html to the repository's top level.
3. Open the repository's Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. Wait for GitHub Pages to publish; it will show the website URL in Settings > Pages.

MUSIC (OPTIONAL)
The music button is ready for an audio file named music.mp3. Put a file you have permission to use beside index.html. The browser will only play it after the visitor taps the music button.

CUSTOMIZATION
- Change the title in the <title> tag.
- Change the letter text inside the element with id="loveLetter".
- Update the promises and section text directly in index.html.
- To add real wedding details, replace the wording with a date, venue, RSVP information, and other details only when you're ready.
